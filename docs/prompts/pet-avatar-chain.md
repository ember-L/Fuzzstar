# 萌宠数字分身：两段式 AI 提示词链路

用户提供真实宠物照片 → 生图模型产出萌化三维底图 → 视频模型以底图为首帧产出动作视频 → 转循环 GIF。

背景色统一 `#FFEDD7`。两段都要求身份一致：模型的任务是"让同一只宠物动起来"，不是"重新画一只宠物"。

---

## 第一段：生图模型（照片 → 萌化三维底图）

```
输入：用户提供的宠物照片（可多张：图片1、图片2、图片3……）。

任务：提取照片中宠物的样貌特征，生成一张萌化三维形象图。

特征清单（逐项从照片读取，作为后续所有动作的基准）：
- 物种与花色（如中华田园猫、橘白、三花）
- 毛色分布：主体色与色块位置（额头、背部、胸口、爪子）
- 眼睛颜色与形状、鼻头颜色
- 耳朵形状与朝向、体态与胖瘦、尾长
- 脸型与五官比例

生成要求：
- 必须是同一只宠物：毛色、花纹位置、五官、体态与照片一致，不换色、不换品种。
- 画风：可爱三维质感，圆润、柔和，保留照片的写实比例；不卡通化到失真。
- 构图：正面全身，宠物居中，占画面约 75%，四边留白均匀。
- 镜头固定、平视，不俯拍不仰拍。
- 背景：纯色 #FFEDD7，无渐变、无纹理、无道具、无文字、无水印。
- 输出：正方形。

禁止：额外肢体、畸形、多只宠物、人类特征、文字、水印。
```

---

## 第二段：视频模型（底图 → 动作视频）

```
输入：第一段生成的萌化三维底图，作为首帧。

任务：以首帧为唯一外观基准，生成一段 1–5 秒的动作视频。

硬约束：
- 首帧即最终形象：毛色、花纹、五官、体态与首帧完全一致，不重新生成外貌。
- 镜头不移动：不推拉、不摇移、不旋转。
- 宠物整体保持在画面中，居中，占画面约 75%，不走出画面、不整体位移。
- 背景保持纯色 #FFEDD7，不变化、不出现道具。
- 动作幅度小、节奏慢、写实；不夸张、不大开大合。
- 画风偏可爱，与首帧照片风格一致。

本次动作：<从下方动作表选一条，原样填入>

禁止：换色、变形、换背景、镜头运动、多只宠物、文字、水印、
      大幅跳跃或旋转。
```

## 实测踩坑（写提示词时按这些调整）

1. **不要写工程约束**。例如"首尾帧对齐可无缝循环"模型无法执行，会分散对动作的注意力；循环由转 GIF 时设置，不靠提示词。
2. **身份锁定句放最前**。"保持首帧里同一只宠物的外观与毛色"这类指令要放在动作描述之前，否则模型容易重画外貌。
3. **避开审核误判词**。实测这些无害表述会触发内容审核（错误码 1301）：
   - "张大嘴" → 改"嘴巴轻轻张合一次"
   - "趴卧闭眼" → 改"安静趴卧闭眼"
   - "转向右侧" → 改"头部转向右侧，稍停后回正"
   判定依据是生成内容，不是单个词，但换中性表述后通过率明显提高。
4. **多张照片的用途**：图片 2、图片 3 用来补充花色与五官细节，最终以信息最全的一张为正脸基准；不要要求模型"融合"。
5. **时长**：视频模型通常只接受固定档位（常见 5 秒），提示词写 1–5 秒即可，实际取模型支持的最短档，再由后处理裁到规格内。
6. **背景色**：底图与视频两段的 `#FFEDD7` 必须一致，否则首帧与后续帧会出现色差接缝。

---

## 输出规格

- 底图：正方形，居中，背景 `#FFEDD7`
- 视频/ GIF：≤7 秒、高 480、12fps、无限循环
- 失败降级：单动作失败不影响其他动作，缺失动作回退待机动图
