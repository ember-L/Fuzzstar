# 绒星 RongXing · 产品 Brief

> 星光护绒，健康相伴。

## 产品概述

绒星是一款面向猫主人的 AI 宠物健康管理 App。它以每只猫的专属档案和数字分身为中心，将健康初筛、日常记录与情感互动连接起来，帮助主人更早留意变化、更有条理地照顾猫咪。

**一句话定位：** 一位有温度的猫咪健康管理伙伴。

## 机会与用户需求

猫咪不善于表达不适，新手主人常常难以判断异常是否需要就医；多猫家庭则需要更轻松地管理每只猫的饮食、体重和健康记录。与此同时，主人希望更了解猫咪的状态，并获得有陪伴感的互动体验。

| 用户 | 典型需求 |
| --- | --- |
| 新手猫主（25–35 岁，养猫不足两年） | 发现异常时，知道该继续观察还是尽快就医。 |
| 资深多猫家庭（28–40 岁，两只猫及以上） | 分别管理猫咪档案，减少记录负担，查看变化趋势。 |

首版仅支持猫；其他物种属于后续探索。

## 核心价值

1. **安心守护**：通过结构化问卷与规则分级，帮助主人识别需要关注的情况；命中急症红线时直接提示立即就医。
2. **专属陪伴**：由猫咪照片生成数字分身，结合健康状态和互动表现，让日常照护更有温度。
3. **持续了解**：把初筛、饮食、体重和历史记录汇集到同一档案，方便观察变化与复查。

## 首版核心体验

| 体验 | 用户可以做什么 |
| --- | --- |
| 猫咪档案与数字分身 | 建立和切换猫咪档案，上传照片生成专属分身，查看健康状态与近期记录。 |
| 健康初筛 | 回答症状问卷，获得分级与下一步建议；需要复查时收到提醒。 |
| 情绪互动 | 录制叫声获得娱乐性情绪解读，并通过文字或录音与猫咪人设对话。 |
| 日常健康管理 | 记录饮食与体重，查看喂养参考和历史健康档案。 |

**主要旅程：** 创建档案 → 上传照片生成分身 → 日常记录或发起初筛 → 查看状态与建议 → 按需复查，记录持续沉淀。

## 品牌与设计方向

- **品牌关键词：** 温暖、安心、亲近、可信、轻盈。
- **品牌角色：** 陪主人细心观察和记录的伙伴，表达亲切，遇到需要就医的情况则清晰直接。
- **视觉方向：** 以圆润、柔软的猫咪形象建立亲和力；可参考已探索的橘猫、明亮橙色和柔和 3D 质感。整体界面应兼顾可爱与信息清晰，紧急状态有醒目、易辨识的提示。
- **语言语气：** 日常交流温柔简洁；健康信息具体、克制，不制造恐慌，也不夸大 AI 能力。

## 产品边界

- AI 内容仅供日常健康管理参考，**不替代专业兽医诊断**；相关提示应在初筛结果和聊天上下文中清晰可见。
- 红线症状由确定性规则直接触发立即就医提示，不依赖大模型判断；红线初筛不限额。
- 叫声情绪解读定位为娱乐性参考，不承诺准确识别；初筛照片和视频仅用于存证，首版不进行 AI 诊断分析。
- 尊重隐私：训练授权默认关闭；提供隐私协议、数据删除和账号注销能力。

## 内测与衡量

首版面向 **50–100 名猫主**内测，通过 TestFlight 和安卓 APK 分发。测试期免费；未来订阅模式仅作预留。

| 指标 | 内测目标或用途 |
| --- | --- |
| 周活跃记录宠物数 | 北极星指标，观察是否持续上升。 |
| 7 日留存 | 目标 ≥30%。 |
| 初筛流程完成率 | 目标 ≥70%。 |
| 红线就医提示点击率 | 观察并建立基线，持续关注安全表现。 |
| 聊天周活、人均消息数 | 观察情感互动的吸引力，暂不设考核目标。 |

## 关键假设与风险

- 用户愿意持续手动记录饮食；需要通过内测验证。
- 数字分身的不同动作可能出现形象漂移，需要回退方案和质量观察。
- 健康建议可能被误解为诊断，需要清晰说明边界并突出就医引导。
- 叫声与情绪的对应缺乏充分科学共识，需要保持娱乐性定位和不确定性提示。
